## Python loops and lists

- Floor: "What does `for r in reversed([1, 2, 3])` give for r, in sequence?" Answer: 3, 2, 1. Correct, confidence 95 percent.
- Ceiling: "What does `functools.reduce(lambda g, r: r + 0.5 * g, [1, 1], 0.0)` give?" Answer: 1.0. Incorrect (1.5), confidence 40 percent.
- Misconceptions: none
- Start from: the learner can write a loop over a list in reverse order.

## Rewards and returns

- Floor: "In an episode, does the agent act one time, or one time at each step?" Answer: at each step. Correct, confidence 90 percent.
- Ceiling: "After each action, what does the environment give the agent, in addition to the next state?" Answer: nothing. Incorrect (one scalar reward), confidence 50 percent.
- Misconceptions: the learner thinks that the agent sees its score only at the end of the episode.
- Start from: the agent acts at each step, and the environment gives the next state after each action.
